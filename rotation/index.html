    About this workbench

    This workbench embeds and links to educational simulations from PhET, oPhysics, The Physics Aviary, Gravity Simulator, and others. All rights to the linked and embedded content belong to their respective authors. See each tool's card for source attribution and license.

    Original sims to verify this physics are specced in the build plan; none are built yet. The workbench code is MIT licensed and lives in intuition-deck.

    intuition-deck

    Rotational Motion & Orbital Mechanics

    A working desk for building intuition about spin and orbits: the clearest free simulations on the web, grouped by concept — rotational kinematics, torque and moment of inertia, rolling, angular momentum, and orbital mechanics — each with notes on how to actually use it. Start with the ⚡ cards. Original sims that verify this physics from first principles are specced in the build plan; none are built yet.

    Simulations belong to their authors; each card names its source and license. Workbench code is MIT licensed. intuition-deck on GitHub
