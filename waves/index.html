    About this workbench

    This workbench embeds and links to educational simulations from PhET, Falstad, oPhysics, MIT Mathlets, Walter Fendt, The Physics Aviary, Dan Russell (PSU), and others. All rights to embedded content belong to their respective authors. See each tool's card for source attribution and license.

    The workbench code is MIT licensed and lives in intuition-deck.

    intuition-deck

    Wave Physics Workbench

    A working desk for building intuition about waves: the best free simulations on the web, sorted by topic, each with notes on how to actually use it. Start with the ⚡ cards. The last section is where my own sims will live, built to check the math from first principles rather than just show it.

    Simulations belong to their authors; each card names its source and license. Workbench code is MIT licensed. intuition-deck on GitHub
